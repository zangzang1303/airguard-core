# ADR 0001: Event-driven modular architecture\n\n## Status\nAccepted for MVP.\n\n## Context\nAirGuard needs a traceable simulator-to-dashboard path plus Agent/HITL without coupling frontend or Agent to MQTT/DB.\n\n## Decision\nUse `Simulator -> MQTT -> Consumer -> PostgreSQL -> FastAPI -> React`. Alert/forecast run behind backend services. Agent reaches data through typed backend tools only. Approval and audit remain backend-owned.\n\n## Consequences\nClear ownership, testable contracts and replayable data path; extra consumer/service operational work. Frontend MQTT and Agent DB access are prohibited.\n\n## Verification\nTrace a message_id across all layers; test duplicate, stale, broker/DB outage.\n\n## Supersession\nCreate a new ADR for a material architecture replacement; do not rewrite this decision history.
