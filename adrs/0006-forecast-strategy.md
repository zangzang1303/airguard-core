# ADR 0006: Conservative short-term forecast\n\n## Status\nAccepted for MVP.\n\n## Decision\nForecast only 1-3 hours, using a simple baseline approved by team and optional weather context. Every result includes model/source/generated time/freshness and confidence/limitation where available. Forecast is advisory and never replaces current observation.\n\n## Consequences\nLow implementation risk but limited accuracy; no long-term or medical/operational certainty claims. Replace with a new versioned model only after evaluation.\n\n## Verification\nNo-data/stale/low-confidence handling, horizon bounds and Agent wording tests.
