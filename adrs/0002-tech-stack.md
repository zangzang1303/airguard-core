# ADR 0002: MVP technology stack\n\n## Status\nAccepted for MVP.\n\n## Decision\nFastAPI/Pydantic for API and validation; PostgreSQL persistence; Mosquitto MQTT; React + TypeScript + React Leaflet/OSM dashboard; Docker Compose local orchestration; LangGraph/tool-calling Agent; Celery/Redis only if background work needs it.\n\n## Rationale\nStack matches existing project direction, supports typed contracts and can run locally.\n\n## Constraints\nDo not add a second database, broker, frontend framework or agent framework without ADR. Version pinning, environment variables and healthchecks are required.\n\n## Open\nExact auth and weather provider remain subject to team/Mentor confirmation.
