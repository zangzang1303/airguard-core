# User Stories

| ID | Story | Acceptance summary | Priority |
|---|---|---|---|
| US-001 | As a viewer, I see 5 stations on a map | marker/name/status/current/source/time visible | P0 |
| US-002 | As a viewer, I inspect history | selectable station, ordered valid history, empty/error state | P0 |
| US-003 | As a viewer, I distinguish stale/offline | UI labels source and freshness, not live claim | P0 |
| US-004 | As a viewer, I see active alerts | severity/tram/time/value and focus map action | P1 |
| US-005 | As a user, I ask current PM2.5 | Agent calls tool and cites station/time/source | P1 |
| US-006 | As a user, I compare stations | Agent calls compare/history data, explains scope | P1 |
| US-007 | As a user, I ask forecast | Agent returns 1-3h data with limitation/confidence | P1 |
| US-008 | As sensitive/sport user, I get tailored advice | profile policy applied; no medical diagnosis | P1 |
| US-009 | As a manager, I review proposal | approve/reject requires role and creates audit | P1 |
| US-010 | As team, I rehearse demo | runbook produces repeatable evidence | P1 |

All stories require loading/error/empty states and must preserve simulator disclaimer.
