## Known limitations và observations

- Normal dashboard là dữ liệu đang chạy liên tục; alert count có thể thay đổi giữa API baseline và thời điểm screenshot.
- `GET /api/v1/alerts` hiện gọi `evaluate_all_current()`. Nếu manager resolve alert trong lúc current PM2.5 vẫn trên ngưỡng, lần GET sau có thể tạo alert active mới. QA đã ghi nhận behavior này thay vì sửa DB để che nó.
- Current station response không cung cấp `message_id`; proposal evidence vẫn có PM2.5/source/alert ID, còn measurement IDs được đối chiếu trực tiếp từ DB.
- Không chụp màn hình proposal/device vì API + DB + MQTT logs + audit IDs đã cung cấp evidence replayable và tránh lộ thông tin tài khoản demo.
