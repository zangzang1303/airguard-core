## Known limitations và test-command corrections

- Ảnh Network do người kiểm thử cung cấp trong phiên chat chưa được lưu thành file repo; DOM check replayable đã xác nhận chính xác error banner.
- Một recovery request gửi bằng Windows PowerShell gặp lỗi encoding JSON tiếng Việt; request được replay bằng Python UTF-8 và trả HTTP 200. Đây là lỗi command kiểm thử, không phải lỗi service.
- Truy vấn MQTT đầu tiên dùng nhầm `received_at`; schema thật dùng `created_at`. Scenario được replay với truy vấn đúng và số liệu trong evidence này là kết quả replay.
