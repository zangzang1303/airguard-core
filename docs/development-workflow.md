# Development Workflow\n\n1. Read AGENTS, task, specs/ADR and existing tests. 2. Create/claim a small task with acceptance criteria. 3. Inspect code/contracts with `rg`; preserve unowned changes. 4. Implement with contract/migration considerations. 5. Run focused test, lint/build and integration smoke relevant to change. 6. Update contracts/docs/ADR when interface or decision changes. 7. Open PR with evidence, risks and rollback note. 8. Update handoff AI log when work remains.\n\nDefinition: done is not "code compiles"; it includes error paths, safety constraints, docs and test evidence.
