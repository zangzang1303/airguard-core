# Security Guidelines\n\nSecrets live in environment/secret store only; redact them from logs, errors, screenshots and prompts. Validate HTTP/MQTT/tool input; enforce server-side RBAC; CORS allowlist; use parameterized DB access; least privilege per service. Agent receives no DB/MQTT credentials and no approve/reject tool.\n\nTreat simulator data as non-official but protect user profile/audit metadata. Audit material actions, retain minimally, avoid raw sensitive prompts. On leak: revoke/rotate, remove from tracked history per team process, assess exposure and document incident. Never expose control command without approved server-side reference.
