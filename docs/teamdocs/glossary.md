# Glossary\n\n**PM2.5** particulate measurement used in MVP. **Fresh** valid data within configured SLA. **Stale** data older than SLA. **Invalid** schema/range/policy failure. **Offline** station has not sent heartbeat/valid data per policy. **Grounding** answer facts derive from tool result. **HITL** manager reviews proposal. **Proposal** pending request, not executed command. **Alert** rule-engine outcome. **Audit log** append-only material action record. **Idempotency** retry does not duplicate effect. **Source=simulator** explicitly synthetic demo provenance.
