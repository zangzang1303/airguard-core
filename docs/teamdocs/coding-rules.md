# Coding Rules\n\nPython: typed functions, Pydantic at boundaries, explicit error mapping, repository/service separation, timezone-aware datetimes, no raw secrets/logging. TypeScript: strict types, API client types, no business alert logic/MQTT client, loading/error/empty UI states.\n\nAll: validate untrusted input; use idempotency for MQTT/job/mutation; name status enums consistently; no magic threshold in UI/routes; structured logs with correlation id; comments only for non-obvious decisions. Tests cover valid, invalid, stale, duplicate, timeout and authorization paths where applicable.
