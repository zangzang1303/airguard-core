# Environment Setup\n\nInstall Docker Desktop/Compose, Python and Node versions required by project files. Copy `.env.example` to `.env`; supply only local secrets and never commit it. Start dependencies first (PostgreSQL, Mosquitto), then migrations/seed, backend/consumer/worker, simulator, frontend. Verify health/readiness, `GET /api/v1/stations`, MQTT publish logs and dashboard.\n\nTroubleshoot: readiness 503 means inspect dependency logs; empty map means verify seed/API/CORS; no fresh data means simulator topic, consumer log and last_seen; do not bypass validation with DB edits. Record local deviations in AI log.
