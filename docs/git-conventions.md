# Git Conventions\n\nUse short branches: `feat/<area>-<summary>`, `fix/<area>-<summary>`, `docs/<summary>`, `chore/<summary>`. Conventional commits: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`. Keep one coherent change per commit. Never commit `.env`, credentials, generated local DB/logs or unrelated formatting.\n\nPR must state purpose, contracts changed, test commands/results, screenshots for UI, migration/rollback, known risks and docs updated. Do not force-push shared work, reset hard, or revert another contributor without explicit agreement.
