# Definition of Done

Code/config/docs complete; focused tests pass with evidence; valid/error/security paths covered; contracts/ADR updated; no secret/PII leak; observability/audit added where material; UI has loading/error/empty state; review complete; runbook/known limitation updated.

For Agent, tool grounding and safety evaluation must pass. For HITL, RBAC, concurrency and no-dispatch-before-approval must be verified.
